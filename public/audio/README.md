# Música de Fundo - Arcade

## Como Adicionar Música

1. Coloque seu arquivo de áudio (MP3, OGG, ou WAV) nesta pasta `public/audio/`
2. Renomeie o arquivo para `arcade-music.mp3` (ou o formato que preferir)
3. No arquivo `src/components/organisms/BackgroundMusic.jsx`, descomente a linha:
   ```jsx
   src="/audio/arcade-music.mp3"
   ```

## Sugestões de Música Arcade

- Músicas chiptune estilo 8-bit/16-bit
- Trilhas sonoras de jogos retrô
- Synthwave ou retrowave
- Músicas com batidas eletrônicas nostálgicas

## Formatos Suportados

- MP3 (recomendado)
- OGG
- WAV
- AAC

## Controles

O controle de música aparece no canto inferior direito da tela com:
- Botão play/pause
- Slider de volume
- Efeitos neon animados
